Background music. The assembler picks one track per episode, lowers it ~20 dB under the
narration and dips it further while someone speaks.

The tracks here are composed by `tools/make_music.py` (tanpura, bansuri-like flute and soft
mridangam-like drum in Carnatic ragas, synthesised from scratch): the channel owns them outright,
so there is no copyright claim, licence or credit to give. Run it again to remake them.

Any other royalty-free file (.mp3/.wav/.m4a) can be dropped in too; keep its licence/credit in a
sidecar `<file>.txt` if the licence asks for attribution.
